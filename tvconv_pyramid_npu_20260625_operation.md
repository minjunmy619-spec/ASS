# TVConv Pyramid NPU Separator Operation Notes

Date: 2026-06-25

## Goal

Implement and verify a new NPU-first speech/music/effects separator candidate
for TV adaptive audio, rather than only tuning existing ASS model variants.

Primary deployment idea:

- Explicitly estimate speech and music.
- Reconstruct effects/SFX as `mixture - speech - music` in the wrapper.
- Keep the streaming core under the 192 KiB fp16 layer-cache state budget.
- Prefer Conv2D and stride-2 ConvTranspose2D fast paths over many small memory
  ops or attention/BMM-heavy student blocks.

## Literature Signals Used

- SFC/SFC-CA shows that frequency compression is important for source
  separation quality, but its BMM/softmax path is not necessarily the best NPU
  student primitive: https://arxiv.org/abs/2602.08671
- Band-SCNet reinforces causal, lightweight, compressed-frequency modeling for
  realtime separation: https://www.isca-archive.org/interspeech_2025/yang25d_interspeech.pdf
- RT-STT and Moises-Light support the value of practical lightweight
  spectrogram-domain U-Net/TFC-TDF style models for realtime or efficient
  music separation: https://arxiv.org/abs/2511.13146 and
  https://arxiv.org/html/2510.06785v1
- SDX23 robust MSS formalizes label noise and bleeding as first-class training
  problems, which matches pseudo-label datasets generated by large separators:
  https://arxiv.org/html/2308.06979v4
- DnR-nonverbal highlights that speech labels must include non-verbal vocal
  events such as laughter/screams; this matters for TV sports/concert content:
  https://www.isca-archive.org/interspeech_2025/hasumi25_interspeech.pdf

## Implemented Architecture

New primary core:

- `spectral_feature_compression/core/model/tvconv_pyramid_npu_separator_2d.py`
- Builder:
  `spectral_feature_compression.core.model.proposed_separation_models.build_tvconv_pyramid_npu_separator_system`
- Recipe:
  `recipes/dnr/models/tvconv-pyramid-npu.speech-music-residual-sfx.robust-distill.rt192k.fp512keep475/config.yaml`

Core structure:

1. Packed complex STFT input `[B, 2*C, T, F]`.
2. Frequency pyramid encoder with stride-2 Conv2D downsampling only along
   frequency.
3. Compact bottleneck at `F=32` for the fp512 deployment path.
4. Six causal temporal bottleneck blocks with state stored before expansion,
   so the layer cache stores only bottleneck channels.
5. Frequency decoder with stride-2 ConvTranspose2D and additive skip paths.
6. Source-folded complex mask head for speech/music.
7. Residual SFX reconstruction in `FrequencyPreprocessedOnlineModel`.

Important design correction:

- Pooled capacity mixers are disabled by default (`capacity_hidden: 0`).
  Capacity is spent in real bottleneck/source paths instead, because previous
  evidence showed pooled mixers add parameters without proportional separation
  gains.

## Review Fixes

The review found several places where the implementation did not yet match the
intended training behavior. Fixed items:

- The primary TVConv recipe now uses the TV on-the-fly profile datamodule
  directly instead of the older HDF5 mixer.
- Training can request true model aux outputs with `request_model_aux: true`.
  `ModelWrapper`, `OnlineModelWrapper`, `FrequencyPreprocessedOnlineModel`, and
  the RoFormer teacher preserve `(estimate, aux)` outputs.
- TVConv and RoFormer expose internal `mask`/`mask_logits` tensors for mask
  distillation. The task crops the shared explicit-source prefix and maps the
  teacher frequency grid to the student grid with `distillation_band_mapping:
  linear`.
- Follow-up hardening made aux distillation domain-aware:
  - TVConv declares `mask_domain`, `mask_logits_domain`, and the
    `sigmoid_tanh_complex_mask` inverse-logit transform with its real/imag mask
    scales.
  - RoFormer exposes `mask` plus true `mask_logits`; because the RoFormer mask
    head has no post-projection activation, the final projection is both the raw
    RoFormer-domain logit and the complex mask.
  - The TVConv recipe sets `teacher_logit_loss_weight: 0.05`. The distillation
    task does not compare raw RoFormer logits against raw TVConv logits; instead
    it converts the teacher `packed_complex_mask` into the student's TVConv
    logit coordinates when the student declares the matching transform.
  - The recipe sets `require_model_aux: true` and explicit shared-prefix mask
    alignment with a bounded frame-mismatch tolerance.
- Residual-mode `mixture_consistency_weight` is set to `0.0` in the recipe,
  because residual SFX already enforces exact sum consistency by construction.
- New source-aware objectives train what mixture consistency could not:
  source-weighted SNR, explicit speech/music robust loss, and residual SFX robust
  loss.
- The TVConv complex mask head now has configurable `real_mask_scale`; the
  recipe uses `1.5` so speech/music estimates are not capped at mixture
  magnitude.

## Remaining Work

This is compile/export validation, not separation-quality validation.

Next required experiments:

1. Train the ConvPyramid recipe with the TV-profile datamodule.
2. Compare against `source-aware-melband-loco-cnb` and `BandSFCNet-RT+` on:
   - speech SDR/SI-SDR,
   - music SDR/SI-SDR,
   - SFX leakage,
   - karaoke vocal-removal listening clips,
   - football commentary/ambient control listening clips.
3. Run quantization-aware or post-training quantization quality checks using
   real calibration clips, not random ONE fallback calibration.
4. If quality is below the Loco-CNB/SFC students, try:
   - widening `base_channels` before increasing stateful bottleneck channels,
   - adding one non-stateful full-band refinement block,
   - training with teacher mask/logit distillation from the RoFormer teacher.
